# Why score-based generative models add noise

Interactive figures for the three pitfalls of score matching on real data,
and what Gaussian perturbation does about each.

Live: https://USERNAME.github.io/REPO/

| page | content |
|---|---|
| `index.html` | landing page |
| `slide.html` | all three pitfalls as one 16:9 presentation slide |

Every page is a single self-contained HTML file: no dependencies, no CDN,
no build step. Open any of them directly from disk, or serve the folder
statically.

Follows Song & Ermon, *Generative Modeling by Estimating Gradients of the
Data Distribution*, NeurIPS 2019 (arXiv:1907.05600).
